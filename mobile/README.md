# SuperDev Mobile

Mobile client for SuperDev AI Suite.

## Platform

- **Framework**: Flutter
- **Language**: Dart
- **Minimum SDK**: 3.0.0

## Features

- Chat with AI agents
- View projects and workflows
- Monitor deployments
- Receive notifications
- Basic code editing

## Setup

```bash
flutter pub get
flutter run
```

## Build

```bash
# Android
flutter build apk

# iOS
flutter build ios
```

## Structure

```
lib/
  main.dart
  screens/
    home_screen.dart
    chat_screen.dart
    projects_screen.dart
    settings_screen.dart
  services/
    api_service.dart
    notification_service.dart
  widgets/
    message_bubble.dart
    project_card.dart
```
