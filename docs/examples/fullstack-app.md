# Fullstack App Example

A complete web application with Next.js.

## Setup

```bash
superdev init my-app --template next
cd my-app
superdev dev
```

## Features

- Server-side rendering
- API routes
- Authentication
- Database integration
- Real-time updates

## Structure

```
src/
  app/
    layout.tsx
    page.tsx
    api/
      users/route.ts
      projects/route.ts
  components/
  lib/
    db.ts
    auth.ts
```
