# Chatbot Example

An AI-powered chatbot using SuperDev's chat API.

## Setup

```bash
superdev init my-chatbot --example chatbot
cd my-chatbot
superdev dev
```

## Features

- Real-time streaming responses
- Conversation history
- Model selection
- Provider switching
- File attachments

## Backend

Uses FastAPI with WebSocket for real-time streaming.

## Frontend

React chat interface with:
- Message list
- Input area
- Model selector
- Provider selector
