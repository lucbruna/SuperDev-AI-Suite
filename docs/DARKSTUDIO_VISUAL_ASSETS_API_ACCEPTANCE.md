# Critérios de aceite — API visual

- [ ] POST de prévia retorna briefings sem persistir alterações.
- [ ] POST com aplicação persiste plano e briefings por cena.
- [ ] Aplicação não substitui imagem ativa nem inicia geração.
- [ ] Job não concluído recebe conflito.
- [ ] Operação de render ativa impede aplicação do plano.
- [ ] GET retorna plano persistido ou sinaliza ausência.
- [ ] GET de candidatos ordena por metadados e não expõe caminhos absolutos.
- [ ] Cena inexistente e job inexistente retornam 404.
- [ ] Testes unitários executados e aprovados em CI.
- [ ] Painel integra as rotas e mostra estado de revisão humana.
