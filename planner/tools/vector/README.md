# Vector Tools

Tools for vector embedding, storage, search, and management.

## Components

- **Embedding**: engine, cache, models, registry
- **Storage**: vector_database, vector_store, vector_index, vector_repository
- **Search**: vector_search, similarity, cosine_similarity, euclidean_distance, manhattan_distance
- **Indexes**: hnsw_index, ivf_index, pq_index
- **Retrieval**: retriever, reranker, hybrid_search, semantic_search, lexical_search
- **Processing**: chunking, splitter, tokenizer, ingestion
- **Pipeline**: synchronization, garbage_collector, optimizer
- **Data**: document_loader, metadata_filter
- **Operations**: backup, restore, encryption, compression
- **Observability**: health, metrics, statistics, validator
