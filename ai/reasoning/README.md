# Reasoning Engine

The Reasoning Engine analyzes context, generates hypotheses, evaluates risks,
chooses strategies, and validates results before executing actions.

While the Planner answers *"What needs to be done?"*,
the Reasoning Engine answers *"What is the best decision?"*

- **Quality**: reasoning_validator, reasoning_optimizer, reasoning_security, reasoning_permissions
